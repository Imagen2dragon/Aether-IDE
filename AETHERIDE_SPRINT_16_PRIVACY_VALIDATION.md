## 1. Executive Summary

This report documents the privacy audit and network egress inspection performed on AetherIDE `v0.1.0-beta.2`. Modern developer environments frequently bundle opaque telemetry libraries, crash reporting agents, and analytics beacons that silently transmit developer source code, file paths, and behavioral habits to third-party cloud infrastructure.

AetherIDE is built on a foundational principle of **Zero-Telemetry**. The codebase, desktop hosts, background daemon, and web frontend contain zero tracking SDKs, zero analytics beacons, and zero automatic crash reporters. Source code, project brain indexes, credentials, and conversation transcripts remain strictly on the local workstation unless explicitly directed to a user-configured AI model provider.

## 3. Diagnostic Report Sanitization

AetherIDE provides a **Help > Export Diagnostics** utility that allows developers to package debugging information when reporting defects. This utility enforces strict automated redaction before writing the diagnostic bundle:

### 3.1 Credential & Secret Scrubbing
- Regular expressions identify all keys matching API token schemas (e.g., `sk-ant-*`, `sk-*`, `AIza*`, Bearer tokens).
- Found secrets are replaced with `[REDACTED_SECRET]` or cryptographic hashes.
- Environment variables containing strings `KEY`, `TOKEN`, `SECRET`, `PASSWORD`, `AUTH`, or `CREDENTIAL` are completely excluded from the dump.

### 3.2 Path & User Identity Sanitization
- Local username components in paths (`C:\Users\<username>\...` or `/home/<username>/...`) are replaced with `~` or `<USER_HOME>`.
- Machine hostnames and internal MAC addresses are replaced with randomized pseudonyms.

### 3.3 Explicit User Consent & Review
- The sanitized JSON report is written to a human-readable file (`aether-diagnostics.json`).
- A confirmation dialog displays the full text to the developer before saving, ensuring full visibility into exported data.

## 4. Complete Offline & Air-Gapped Operation

AetherIDE is fully capable of running in an air-gapped, zero-internet environment:
1. All web assets (Monaco Editor, xterm.js, Cytoscape.js, CSS fonts) are bundled locally in the application package. No CDN calls (`cdnjs`, `unpkg`, `fonts.googleapis.com`) are executed.
2. When paired with local LLMs (via Ollama, LM Studio, or llama.cpp), code completion, agent planning, and diff generation operate completely offline.
3. The daemon operates with full fidelity when network interfaces are physically disconnected or firewalled.

## 5. Local Storage & File Containment Audit

All state generated by AetherIDE is contained within predictable, inspectable boundaries:

```text
User Project Directory/
└── .aether/
    ├── brain.db           (Local SQLite FTS5 symbol and file index)
    ├── brain.db-wal       (SQLite Write-Ahead Log)
    └── session.token      (DPAPI/Keychain encrypted session key)
```

- **No Global Leakage:** AetherIDE does not write temporary build artifacts, source code caches, or AST trees into global system directories (`C:\ProgramData`, `/var/tmp`, `/etc`).
- **Clean Deletion:** Deleting the `.aether/` directory completely purges all IDE-generated metadata from the workstation.
