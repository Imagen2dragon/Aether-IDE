Cold launch to interactive editor in under 1.4 seconds. Daemon bootstrap takes only 184ms with minimal disk I/O.

Strict filesystem security via cap-std. AI agents and workbench tools cannot escape workspace directory roots.

Zero background telemetry, tracking SDKs, or analytics pings. Code remains strictly local or sent only to your configured AI provider.
