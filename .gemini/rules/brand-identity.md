# AetherIDE — Immutable Brand Identity & Logo Protection Rule

## Directive: Permanent Main Project Logo

The visual brand identity located in `branding/` is the **permanent, official, canonical main logo** for AetherIDE.

### Core Rules:
1. **Never Modify or Regenerate:** The agent must **NEVER** alter, modify, regenerate, replace, redesign, or overwrite the project logo, app icon, or brand identity files unless the user directly and explicitly instructs the agent to do so in clear, unambiguous words.
2. **Canonical Asset References:**
   - Vector Symbol: `branding/source/aetheride-symbol.svg`
   - Vector Logo & Wordmark: `branding/source/aetheride-logo.svg`
   - Master 3D Icon: `branding/png/aetheride-render-3d.jpg`
   - Standard Raster Icons: `branding/png/aetheride-icon-*.png` (16, 24, 32, 48, 64, 128, 256, 512)
   - Windows ICOs: `branding/windows/aetheride.ico`, `branding/windows/aetheride-installer.ico`, `apps/desktop/src-tauri/icons/icon.ico`
   - Website Favicons: `website/assets/favicon.ico`, `website/assets/favicon.png`
3. **Usage Consistency:** Any newly built component, documentation page, website view, or installer must consistently use these canonical assets without creating alternative logos.
