## 3. Disambiguating GitHub Artifact Digests vs. Package Hashes

GitHub Actions exposes two distinct cryptographic digests for each build output:

1. **GitHub Artifact Digest:** The SHA-256 hash of the parent container zip generated by `actions/upload-artifact@v4` when transferring files through the GitHub Actions API.
2. **Inner Package Hash:** The SHA-256 hash of the actual release archive (`.zip` on Windows, `.tar.gz` on Linux/macOS) distributed to end developers.
