## 3. Staged Draft Release Notes

Below is the verbatim markdown staged for the GitHub Release body:

```markdown
# AetherIDE v0.1.0-beta.2

AetherIDE is an AI-native integrated development environment engineered in Rust for maximum performance, minimal memory consumption, strict developer privacy, and safe multi-agent code synthesis.

This release represents our **Beta.2 Milestone**, establishing native desktop hosts across Windows, Linux, and macOS, zero-trust IPC daemon architecture, and capability-based filesystem security.

---

### Key Features & Subsystem Highlights

- **Native Cross-Platform Desktop Hosts:**
  - **Windows:** Win32 host embedding Microsoft Edge WebView2 Evergreen with ConPTY terminal integration.
  - **Linux:** Native GTK3 and WebKitGTK host with FreeDesktop Secret Service vault.
  - **macOS:** Apple Silicon native Cocoa (AppKit) host embedding hardware-accelerated WKWebView.
- **Zero-Trust IPC & Native Credential Vaults:**
  - Headless `aether-daemon` binds strictly to localhost loopback (`127.0.0.1`) and native OS Named Pipes / Unix Domain Sockets.
  - API keys and session tokens are encrypted via Windows DPAPI, macOS Keychain, and Linux Secret Service. Zero plain-text credentials on disk.
- **Capability-Based Filesystem Containment:**
  - Complete filesystem isolation via `cap-std`. Agents and workbench tools are strictly confined to active workspace roots. Directory traversal and symlink escapes are deterministically rejected.
- **Project Brain & SQLite FTS5 Indexing:**
  - High-speed local AST and symbol indexer with sub-5ms exact and fuzzy symbol search across multi-language codebases.
- **14 AI Agent Personas with Interactive Diff Review:**
  - Multi-agent collaboration (Planner, Coder, Reviewer, Tester, etc.) produces structured, reviewable unified diffs.
  - Full developer control: side-by-side diff preview with one-click Accept, Reject, and atomic Rollback.
- **Multi-Provider AI Gateway:**
  - First-class support for local offline models (Ollama, LM Studio) and cloud APIs (OpenAI, Anthropic Claude, Google Gemini, OpenRouter) with token streaming and automated fallback.
- **Zero-Telemetry Guarantee:**
  - No analytics beacons, no tracking SDKs, no automated crash reporting. Your code never leaves your computer unless sent to your chosen AI model provider.
